# Comment-Automation website

Static website with four pages: homepage and three separate legal pages.

## Deploy
Upload the files in this folder to any static hosting service (Vercel, Netlify, GitHub Pages, etc.). No build step required.

## Meta App Settings URLs
- Privacy Policy: `https://YOUR-DOMAIN/privacy.html`
- Terms of Service: `https://YOUR-DOMAIN/terms.html`
- Data Deletion Instructions: `https://YOUR-DOMAIN/deletion.html`

## Before publishing
Review the policies to ensure they reflect your actual data processing, retention and deletion practices. Verify the contact email. These templates are not legal advice.
